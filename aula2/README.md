# Aula 2 - Avaliador de Filmes em React

Rodar:

```
npm install
npm run dev
```

Abra o endereço que aparecer (normalmente http://localhost:5173).

Passos da aula (cada arquivo em `passos/` é o conteúdo completo de `src/App.jsx` naquele passo):

1. `passo1.jsx` - primeiro componente
2. `passo2.jsx` - HTML da aula 1 virando JSX
3. `passo3.jsx` - componente `Filme` reutilizado
4. `passo4.jsx` - props `titulo` e `ano`
5. `passo5.jsx` - array de filmes com `.map()`

O CSS (`src/index.css`) é o mesmo da aula 1.
